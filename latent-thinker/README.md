# Latent Thinker compatibility

This plugin and the current latent-mem-lab server do not support system instructions. The manifest deliberately does not declare `chatBackend.sessionConfig`. Hosts that require launch instructions through session configuration refuse agent spawning with `chat_backend_session_config_required`; direct plugin session opens carrying nonempty instructions also fail with `system_instructions_unsupported` before any server request. Instruction-free manual sessions remain supported.

The server currently creates a single user-role message from `/chat`'s `text` field. A future server and plugin release must agree on a separate system-instruction field, apply it as a system-role message in the model's chat template, and retain it for every ordinary and search turn. The plugin must consume `openSession(ctx).systemPrompt` without adding it as a user turn, then declare `sessionConfig` and the minimum host implementing that capability. A server capability handshake must refuse older servers explicitly. Regression tests must prove an opaque instruction reaches that model input, user history stays distinct, incompatible servers refuse before a job starts, and a host spawn reaches its own bound session.
